# Kokan Thali — Taste the Coast

A Konkan-themed React + Vite single-page food ordering experience built as a college assignment prototype. It celebrates coastal Maharashtra through a premium menu, local cart persistence, responsive layouts, and a simulated checkout flow.

## Run locally

```bash
npm install
npm run dev
```

Open the Vite URL shown in the terminal. For a production build:

```bash
npm run build
npm run preview
```

## Included

- Responsive Konkan storefront with sticky navigation, hero story, menu categories, search and sort.
- 12 sample menu items with ratings, dietary markers, favorites and add-to-cart interactions.
- Cart drawer with quantity controls, localStorage persistence, ₹499 free-delivery threshold and dynamic totals.
- Validated simulated checkout with payment-method selection and generated order confirmation.
- Our Story, trust pillars, seasonal offer, testimonials, newsletter form and footer.

The checkout is a prototype: no real payment is processed.
